# Origen del ejercicio

El laboratorio adapta la entidad Promoción del proyecto académico Productos y Ofertas.
Se publican el contrato y las reglas académicas usados en los experimentos, no una copia completa
del repositorio backend ni de su documentación original.
Las siete operaciones del contrato de este repositorio son las únicas interfaces evaluadas.
POST por lote y DELETE lógico son ampliaciones académicas, declaradas en docs/trazabilidad.md.
El manifiesto de publicación registra hashes de los archivos incluidos y las normalizaciones de rutas.
