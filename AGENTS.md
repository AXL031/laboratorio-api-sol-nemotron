# Laboratorio público: modelos y enfoques

A/C son entregas de GPT-6.1 Sol con resultados guardados: conservar código, entradas y evidencia al analizar.
B/D corresponden a Nemotron 3.5 Super VL Free y todavía no tienen resultados. No inventarlos.
Cada caso se ejecuta con un único prompt en su carpeta proyecto/. No copiar soluciones entre modelos/casos.
Spec/plan/tareas son entradas preparadas para C/D; no pedir al modelo que las genere como otra fase.
Cambios posteriores al código deben identificarse como una nueva versión/corrida, sin reescribir evidencia histórica.
No añadir .env reales, tokens privados, dependencias instaladas, datos de bases de datos ni directorios temporales.
Cada DB es local/aislada. Los valores de .env.example son exclusivamente fixtures de desarrollo.
