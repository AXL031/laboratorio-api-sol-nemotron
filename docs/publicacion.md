# Alcance de la publicación

Este repositorio contiene el laboratorio académico, las entregas/evidencias de Sol y entradas preparadas
para Nemotron. No incluye el backend original completo, sus documentos normativos completos, el primer
intento descartado, node_modules, builds, cachés, datos/volúmenes PostgreSQL ni archivos .env reales.

Los valores en .env.example/.env.test.example y Compose son fixtures locales de laboratorio.
No son credenciales de servicios externos. Las conexiones se publican solo en loopback.
Las rutas locales de documentación/reportes se normalizaron en las copias públicas para hacerlas portables;
el manifiesto registra SHA-256 del origen y del archivo público y especifica cada transformación.
No se alteraron código ni entradas congeladas para mejorar los resultados reportados.
Los hashes de snapshots históricos se refieren a los originales medidos; consultar el manifiesto si una
copia documental tiene otra huella por normalización de rutas.
